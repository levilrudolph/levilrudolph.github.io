# levilrudolph.github.io

Static portfolio site (Evergreen design). No build step: GitHub Pages serves these files as they are.

- `index.html` is the home page
- `projects/<name>/index.html` holds the eight project pages
- `assets/css/site.css` is the design
- `images/` holds every photo, GIF, logo and spinning model
- `.nojekyll` tells GitHub to serve the files directly
